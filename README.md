¡Hola JP! Este proyecto se corre en MATLAB.
Dentro del código, el main desplega el menú pero solamente para las ecuaciones de primer, 
segundo y lineales. El código de Lotka-Volterra se corre por aparte. 
Para poder correr el código es necesario crear una carpeta en MATLAB, 
dentro de la carpeta crear 4 scripts y pegar cada código en un script diferente. 
Luego solamente queda que el usuario corra el main 1 vez. Una vez corre, se desplegará 
el menú en el cuál se debe seleccionar que quiere resolverse. 
Una vez elegida la selección, el código automaticamente desplegará las gráficas 
correspondientes a la ecuación para poder analizarlas. 
En este caso las progras están configuradas para nuestras ecuaciones. 
Sin embargo el código es capaz de resolver cualquier ecuación diferencial.
